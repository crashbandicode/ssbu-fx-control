# Project instructions

Use Rust for the in-game Skyline plugin. Keep the product one NRO
(`libssbu_fx_control.nro`). Do not add a second NRO, a helper plugin or a
compiled third-party dependency.

Native Ubuntu commands use `/usr/bin/pwsh -NoLogo -NoProfile -NonInteractive -Command`.
Global routing authority: `/home/intpa/.codex/DELEGATION_ROUTING.md`.
Push only to the Forgejo origin, and only with the operator's permission.

## Effect rules (inherited from Online Deluxe)

- Effect changes stay in visual request paths: no gameplay articles, hitboxes,
  camera request suppression, broad effect deletion, or RNG/simulation changes.
- Default On. Reduced must not silently perform Off: a fighter row offers
  Reduced only when a keep/cull table or EFF sibling exists, and "All =
  Reduced" leaves a row without one On.
- No global `Layout::Draw` hook. Do not patch the overlay's `0x374812c`
  neighborhood.
- Never claim an inferred crash fix or untested game compatibility as verified.
  Evidence recorded with Online Deluxe builds is labeled as such.

## Coexistence

- Hook callbacks keep the `ssbu_fx_control_` prefix and the cdylib links with
  `-Bsymbolic-functions`.
- Do not hook Online Deluxe's scene sites. With Deluxe 0.5.0 or later, read its
  `ssbu_online_deluxe_online_context_v1` export. The plugin's own
  online-latency (`0x16ccab8`) and stage-setup (`0x25d9288`) hooks are
  installed only when neither Deluxe nor a legacy SsbuSync host is loaded.
- New fighter rows: add the name prefix in `src/fighters.rs`; the build fails
  when an Off-table name maps to no fighter or to two.

## Before completing Cargo work

- `cargo test`, `cargo clippy --all-targets -- -D warnings`,
  `cargo build --no-default-features`, `cargo test` in `host/eff-variant`.
- `cargo skyline clippy -- -- -D warnings` and `cargo skyline build --release`
  (or `tools/Build.ps1`).
- Keep optimized debug symbols and SHA-256 manifests outside the repository
  (`tools/package.py --output <dir>`).
- Do not commit Nintendo assets (including extracted `.eff` files),
  third-party compiled NROs, credentials or build caches.
- `src/effects_reduced_family.rs` is generated by
  `tools/generate_reduced_families.py`; edit the generator, regenerate, then
  run `cargo fmt`.
